# opencivitas-fprcm-enti

Support dataset: anagrafica delle **Province e Città Metropolitane** del riparto
FPRCM (Fondo di Solidarietà), 86 enti RSO.

Usato da `datasets/opencivitas-fprcm` per rendere leggibili gli username SIF
del file VAR_FPRCM (denominazione, tipologia, geografia ISTAT).

Fonte: portale OpenCivitas — `Metadati_Enti_FPRCM_{year}.xlsx`.
